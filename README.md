# Shopify Code Sample

This repository contains a code sample demonstrating my experience with Shopify development.

The project showcases how I approach building and structuring Shopify theme components using **Liquid, JavaScript, HTML, and CSS**.

## What This Demonstrates

* Shopify 2.0 theme development
* Liquid templating
* Custom sections and blocks
* Metafields and Metaobjects
* JavaScript functionality and DOM manipulation
* Responsive HTML/CSS implementation
* Reusable and maintainable theme code

This repository was created as a code sample to demonstrate my Shopify development experience and coding approach.
